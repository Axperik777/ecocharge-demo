# EC-87 — два маршрута привлечения

## Архитектура

| Источник / намерение | Вход | Следующий шаг |
| --- | --- | --- |
| Аффилиат / таргет: участие в зарядках | /participate/charge/ | Короткая заявка Charge → CRM → назначение менеджера |
| Аффилиат / таргет: участие в солнечной энергетике | /participate/solar/ | Короткая заявка Solar → CRM → назначение менеджера |
| Аффилиат / таргет: участие в майнинге | /participate/mining/ | Короткая заявка Mining → CRM → назначение менеджера |
| Контент / сообщество / знакомство | /learn/?topic=solar (или charge/mining/ai/ecocoin/energy) | Материал → сохранённый интерес → отдельный запрос консультации |
| Покупка оборудования | /solar/ или /mining/ с выбором оборудования | Подбор оборудования и исходные данные объекта |

Главная — обзор экосистемы. Быстрые партнёрские ссылки ведут на три тематические страницы, а не на главную. На посадочных страницах одна тема и форма, без общего меню и калькулятора доходности. Необязательные настройки связи раскрываются отдельно. RU/EN, US/CA; английский — язык создаваемых рекламных ссылок. Французская локализация не добавлена.

## Что сохраняется и видно команде

- Маршрут первого входа, текущая задача, тема, страна, дата запроса консультации.
- Первый и последний источник, UTM, partner_id / aff, sub_id, gclid / fbclid / msclkid / ttclid.
- При переходе из знакомства в консультацию контакт обновляется по существующим правилам дедупликации; первый источник и когорта сохраняются.
- Интерес к материалам не входит в очередь первого звонка. Таймер консультации начинается с её запроса, а не с подписки.
- В карточке менеджера видна исходная задача. Сценарий первого обсуждения соответствует направлению; покупка оборудования остаётся отдельным намерением.
- После создания кабинета тема и предпочтения переходят клиенту. Запрос разговора из профиля/сервисов создаёт обращение в очереди ответов менеджера. Повторный запрос той же темы использует открытое обращение.
- Изменение темы/маршрута доступно команде в «Результате контакта», с комментарием и проверкой версии записи.

## Длинный маршрут

Материалы по шести темам, локальный прогресс чтения, добровольное сохранение интереса и согласия на новости. Кнопки обсуждения Solar/Charge/Mining ведут на соответствующую страницу участия. EcoGrid Club — материалы и лента; личные приглашения — отдельная программа. EcoCoin описан как проект токена, а не действующий перевод или начисление. EcoGrid AI — направление инфраструктуры, без выдуманной подтверждённой мощности.

## Измерение

CRM сравнивает когорты по первоначальному маршруту, теме и партнёру: контакты, запросы консультации, квалификация, кабинеты, проверенная первая оплата, возраст когорты, срок до неё. Ручная корректировка баланса не считается оплатой. Длинный цикл не объявляется более прибыльным без данных.

События чтения, выбора темы, сохранения интереса и консультации записываются существующим диагностическим механизмом без контактных данных. Внешние GA4 / Meta CAPI / партнёрские postback не подключены. Расходы кампаний и выручка в этом изменении не импортируются: CAC/прибыль требуют такой сверки отдельно.

## Проверка и ограничения

355 тестов проекта прошли. Публичный пакет содержит 15 страниц сайта; 69 проверок модели и границ экспорта. В браузере пройден путь: интерес Solar → консультация с другим источником → та же карточка → админ назначает менеджера → менеджер создаёт кабинет → клиент запрашивает Mining → обращение видно менеджеру. Проверены отдельная очередь знакомства, источник/партнёр/Sub ID, генератор ссылок и мобильные настройки интересов.

GitHub Pages — интерактивный просмотр с общими данными в одном браузере. Данные между устройствами не синхронизируются. Рабочая серверная реализация сохранена в локальном комплекте; публичный экспорт содержит свежие изолированные примеры. Реальные email/SMS, платежи, токен-контракт и запуск рекламы не включены.

Финальная проверка: 355/355 тестов; 320 px RU и 1280 px EN — три посадочные, /learn/ и главная без горизонтального скролла и повреждённых изображений, Manrope. В генераторе CRM подтверждено сохранение lang=en при русской локали CRM.
