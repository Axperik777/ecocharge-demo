# EC-106 — EcoGrid Academy

1 октября 2026.

## Решение пользователя

Компактная академия объясняет, вовлекает и учит пользоваться EcoGrid. Это дополнительный вход в экосистему вместе с Club. Не строить большую образовательную платформу и не считать регистрацию кошелька подтверждённым интересом к инвестициям.

## Реализовано

- Отдельная страница `/academy/`, RU/EN. Входы в общей навигации, меню, футере, на главной и в Club.
- Три независимых практикума: первый полезный запрос к AI; EcoCoin, кошелёк и применение подарка; общение в Telegram/Facebook.
- AI: три сценария (своё дело, повседневный план, новая тема), редактируемая задача до 700 символов, локальный конструктор запроса, копирование, инструкция по проверке ответа. Генерацию ответа AI этот модуль не имитирует.
- EcoCoin: сначала применение, затем совместимость кошелька, защита доступа, получение и проверка операции. Сеть, контракт и поставщик кошелька не выдуманы. CTA ведёт к существующей форме Club.
- Сообщество: пример содержательного комментария с копированием, переход к существующим соцсетям клуба. Ссылки на реальные каналы всё ещё ожидаются от владельца.
- Раскрывающиеся уроки доступны без регистрации; прямые ссылки `#lesson-ai`, `#lesson-coin`, `#lesson-community`, также `?lesson=ai` и другие разрешённые ID.
- Добровольные отметки прохождения с отменой сохраняются в localStorage `ecogrid-academy-progress-v1`. Это локальные отметки чтения, не подтверждение создания кошелька, получения токена или реального использования AI.
- Введённый текст не сохраняется и не отправляется. При недоступном буфере обмена текст выделяется для ручного копирования; ошибки хранилища не мешают чтению.
- Бесплатный базовый AI клуба не требует расходования EcoCoin. Нет отдельной регистрации в академии, кредитов на счёт или изменений финансовой модели.

## Измерение

События добавлены в существующую **локальную** диагностику `EcoChargeFunnel`, без внешней отправки:

| Событие | Когда | Поля |
|---|---|---|
| page_view | Открытие страницы | page=academy |
| academy_lesson_opened | Раскрыт урок, включая начальный | lesson |
| academy_task_selected | Изменён сценарий запроса | scenario |
| academy_example_copied | Успешно скопирован запрос/пример | lesson |
| academy_lesson_marked | Изменена отметка пользователя | lesson, complete |
| academy_next_clicked | Переход к подарку, Club или проектам | destination |

Поля принимаются по спискам разрешённых значений. Тексты запросов, адреса кошельков, контакты и секреты в события не включаются. `lesson_opened` и `lesson_marked` не выдавать за доказанную продуктовую активацию. Для рекламного запуска ещё нужны серверные события выдачи/применения подарка, возвращаемость и квалифицированные обращения.

## Проверка

- 385/385 тестов, включая 4 новых: повреждённый прогресс/отмена, шаблоны обоих языков и лимит ввода, маршруты без стены регистрации, отсутствие персональных данных в событиях.
- Шесть локальных сборок; переносные исходники внесены в project-map.json.
- 20 адаптивных состояний: Academy RU/EN на 320/390/768/1280 CSS px; входы с главной и Club RU/EN на 320/390/1280 CSS px. Горизонтального переполнения не выявлено.
- В браузере проверены редактирование/смена сценария/копирование, сохранение отметки после перезагрузки, RU→EN, копирование примера комментария, открытие урока по якорю и переход к форме Club. Ошибок JS в проверенных состояниях нет.
- Публичная граница проверена: 17 страниц; прежние кабинет/CRM; 84 проверки связанного просмотра; приватные данные исключены.

## Границы готовности

Страница и учебные действия работают. Автоматическая выдача EcoCoin, сеть токена, AI-сервис, серверная доставка заявок и реальные соцсети этим этапом не подключаются. GitHub Pages остаётся изолированным браузерным просмотром. Физический телефон не проверялся.
