EcoGrid: воронка, CRM и кабинет

EC111 · 1 октября 2026 · Проверка текущей реализации и границ готовности.

Вывод

Логика верхней части воронки — 8/10. Дизайн и удобство — 8/10. Это экспертная оценка структуры, а не доказанная конверсия. Два намерения аудитории разделены: конкретный проект приводит к презентации; интерес к сообществу — к Академии и освоению продуктов.

До запуска трафика нужен работающий переход в Telegram и серверная регистрация. GitHub Pages остаётся изолированной демонстрацией: заявки и изменения CRM там хранятся в браузере, а не доставляются в рабочую базу.

Согласованные маршруты

Реклама проекта → конкретная посадочная → заявка → CRM → презентация → кабинет → решение об участии.
Реклама сообщества / сайт → Club → Academy → Telegram-бот → единый аккаунт → группы → кабинет → кошелёк и EcoCoin → полезный урок.

Для рекламы самой Академии можно вести прямо на её короткую страницу. Звонок предлагается по запросу. Инвестиционный интерес фиксируется отдельно; вступление в сообщество не означает согласие на инвестиционный звонок.

Что изменено

  • Подназвания Academy, Club, Charge, Solar и Mining встроены в соответствующие логотипы. Мобильная шапка исправлена для 320 px.
  • Club остаётся публичной страницей сообщества. EcoCoin описан как его подарок; отдельный пункт и учебная тема EcoCoin убраны.
  • /app/ стал коротким входом в Академию с одним действием — продолжить в Telegram. Старый #club переводит на страницу Club, #ai открывает Академию.
  • PWA относится только к личному кабинету. Установка доступна по ссылкам на сайте и в разделе «Сервисы» кабинета. Старый service worker приложения выводится из использования.
  • В CRM — одна ручная отметка «Состоит в EcoGrid Club», доступная после создания аккаунта. Есть проверка прав, версии записи и история изменений. Баланс и финансовые события от отметки не меняются.
  • Отдельный сценарий Academy RU/EN: регистрация, группы, кабинет, помощь с кошельком, подарок, первый урок. Поля суммы и SPIN скрыты в этом сценарии.
  • Прежний инвестиционный Club-сценарий переименован в программу приглашений, чтобы не смешивать его с открытым сообществом.
  • Пустой кабинет участника Академии начинает с обучения, а не с требования пополнения. Кошелёк показывает баланс и операции. Инвестиционная форма интересов не показывается участнику на этом этапе.
  • CRM-конструктор даёт отдельные ссылки проекта, Club и Academy. Автообновление CRM больше не сбрасывает введённые параметры кампании.
  • Регистрация через Academy/Club не требует подписки на email-рассылку. Один аккаунт используется для обоих маршрутов.

Как сравнивать два маршрута

Проекты: расход → заявка → состоявшаяся презентация → квалифицированный интерес → подтверждённое первое пополнение. Сообщество: расход → запуск бота → единый аккаунт → подтверждённое вступление → первый полезный урок → отдельный инвестиционный интерес → первое пополнение.

Стоимость подтверждённого участника = расход маршрута / подтверждённые вступления. CAC с обработкой = (реклама + стоимость работы сотрудников + фактическая стоимость подарков) / новые платящие клиенты. Сравнивать по первому источнику и одинаковому сроку наблюдения. Дешёвый запуск бота сам по себе не доказывает выгодную воронку.

Следующая итерация: Telegram и регистрация

  1. Вход — бот Академии. Кнопки «Начать», «У меня уже есть аккаунт», «Нужна помощь». У старта — короткий непрозрачный идентификатор источника; не помещать контакты, пароли или полную UTM-историю в ссылку.
  2. Один аккаунт. Бот ведёт на HTTPS-форму официального сервера. Проверенный аккаунт привязывается к Telegram ID через одноразовый ограниченный по времени токен. Повторный запуск не создаёт дубликат.
  3. Группы. Канал Академии — уроки; группа Club — общение. Членство в CRM подтверждается после регистрации и подписок. При недоступной проверке не ставить галочку автоматически.
  4. Доступ в кабинет. Без пополнения, с обычным безопасным входом; PWA — дополнительное удобство после регистрации.
  5. Кошелёк и подарок. Пользователь создаёт кошелёк сам. Бот и сотрудник не получают секретную фразу. Выдача EcoCoin — отдельная операция с защитой от дублей, идентификатором и подтверждённым результатом.
  6. Обучение и помощь. Один короткий урок, одно полезное действие; Telegram-поддержка, при необходимости согласованный звонок. Презентация проекта — отдельное явное желание пользователя.

Для подключения нужны: бот, адреса канала Академии и группы Club, права на проверку подписок, рабочий домен и сервер аккаунтов, правила и технический механизм EcoCoin. Эти подключения в EC111 не реализованы. Пока вместо Telegram-ссылки показано сообщение о подготовке раздела.

Техническая основа: Telegram deep links; getChatMember — проверка других участников гарантирована для бота с правами администратора. Рабочую базу и приватные доступы эта приёмка не меняла.
