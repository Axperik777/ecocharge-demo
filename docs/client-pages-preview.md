# Этап 72 — кабинет на GitHub Pages

29 сентября 2026.

Ссылка: https://axperik777.github.io/ecocharge-demo/cabinet/client/?lang=ru

## Режим публикации

По просьбе пользователя добавлен отдельный статический просмотр клиентского кабинета. Открывается без логина. Это не серверная авторизация: общей базы, приёма заявок, связи с менеджером и реальных операций на GitHub Pages нет. Формы не отправляются, API-запросы кабинета перехватываются только внутри этой статической версии. CRM и рабочая база не публикуются. Локальная платформа продолжает работать отдельно.

## Пример портфеля

- $250 в зарядках, тариф Single / Старт: 13% за календарный месяц.
- Активация на один календарный месяц раньше даты сборки; для этой сборки 29 августа 2026 по местному времени.
- Четыре завершённые недели рассчитаны существующим finance.creditWeek; $30.23 на балансе, текущий незавершённый период отдельно. Даты и суммы зафиксированы в примере; статический сайт не проводит новые недельные зачисления.
- Сохранена демонстрационная ASIC-позиция $5,000 в Канаде. Майнинговых выплат нет; энергетическая ставка к ASIC не применяется.
- Новый изолированный пример создаётся вне рабочей папки данных. Ни база, ни пароли, ни сведения реальных клиентов не читаются для экспорта.

## Файлы

- scripts/export-client-preview.cjs: сборка из project-map, изолированный пример, только клиентские ресурсы.
- dist/pages-client-bootstrap.js, pages-client-adapter.js, pages-client-ready.js: начальные данные, режим просмотра, блокировка отправки форм.
- scripts/verify-client-preview.cjs и verify-public-site.cjs: проверка состава публикации, зависимостей, четырёх недель и сверка сумм с общей финансовой функцией.
- public-site/cabinet в GitHub: отдельная публикация. Основные 11 страниц сайта не менялись.

## Проверка

Автоматический валидатор: 11 страниц сайта и 337 файлов отдельного кабинета; приватных файлов и серверных обработчиков нет. В браузере проверены RU/EN, баланс $30.23, план $250, история четырёх недель, вкладки и блокировка заявки на вывод. На ширине 375 CSS px горизонтальной прокрутки и битых загруженных изображений нет. Полный финансовый набор тестов не перезапускался: серверная логика не менялась.

Для повторной сборки запустить export-client-preview.cjs с --portable, --out (новая папка), --url (адрес папки cabinet с завершающим /), --website. После копирования результата в public-site/cabinet выполнить verify-public-site.cjs public-site и опубликовать workflow GitHub Pages.
