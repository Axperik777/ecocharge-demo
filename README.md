# EcoGrid — публичная презентация

EcoGrid объединяет три самостоятельных направления вокруг общей энергетической инфраструктуры:

- **EcoGrid Charge** — зарядная инфраструктура и отдельная модель участия;
- **EcoGrid Solar** — подбор солнечной системы под объект, тариф и задачу клиента;
- **EcoGrid Compute** — участие в вычислительной инфраструктуре для AI-нагрузок.

Главная знакомит с компанией. Прямой вход на страницу проекта сохраняет проектный контекст. Academy помогает разобраться в выбранном направлении, а Club работает как нефинансовое сообщество.

## Три пути входа

1. Прямая реклама конкретного проекта → его посадочная → Academy → заявка по этому проекту.
2. Материал или тема сообщества → Club → Academy → осознанный выбор проекта.
3. Обучающий вход → Academy → знакомство с компанией или маршрут выбранного проекта.

Изучение страницы или урока не создаёт заявку. Только явный запрос клиента определяет проект для CRM, спича и предложения. Условия Charge не переносятся на Solar или Compute.

Публикация содержит статический интерфейс сайта, кабинета и CRM. Серверная доставка лидов и платёжный провайдер подключаются отдельно; локальные данные браузера не заменяют серверную учётную систему.

## Граница готовности

Код, маршруты, тексты, Academy, клиентский кабинет и обе роли CRM собраны и проверяются единым комплектом. До промышленного запуска остаются три внешних подключения:

1. доставка лидов;
2. платёжный провайдер;
3. финальные юридические документы и подтверждения публичных заявлений.

## Проверка публикации

```sh
node scripts/verify-public-site.cjs public-site
node scripts/verify-knowledge-release.cjs
```

GitHub Actions публикует только `public-site/`. Рабочая SQLite-база, пароли, приватные настройки и серверные маршруты в публичный артефакт не входят. Канонические исходники и полный переносимый комплект находятся в папке `ECO CHARGE`; этот репозиторий хранит только готовую публикацию и её валидаторы.
